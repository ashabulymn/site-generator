# site-generator

A fast drop-in replacement for makefun-site 1.0.0: a static site generator that produces byte-identical output, faster — batched HTML escaping, an index-based Markdown lexer, single-pass inline parsing, memoized slugify and word count, and template compilation with a tree-walker fallback.

## Run it

```sh
node main.ts
```

## The files

- `solve.js`: the generator (Node 22 standard library only, no imports).
- `main.ts`: the harness driver (unchanged from the kit).
- `LICENSE`: MIT.
